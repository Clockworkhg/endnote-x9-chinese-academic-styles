# EndNote X9 中文学术格式工具箱 0.2（可视化便携版）

本工具箱以已经过 EndNote X9＋WPS 基础实测的《中国社会科学（2026）》Alpha 2.7为母版，建立18套中文学术脚注样式、统一多语种参考类型、格式选择页面和测试资料。

## 推荐使用方法

1. 完整解压本压缩包，不要直接在压缩包预览窗口中运行。
2. 双击`打开中文学术格式工具箱.cmd`进入可视化界面。
3. 搜索或选择格式，查看示例后点击“安装选中格式”。
4. 重新打开Word/WPS，在EndNote工具栏的Style中选择所需样式。
5. 用Word/WPS自己的“插入脚注”建立脚注，再用EndNote插入文献。
6. 具体引用页码仍在`Edit & Manage Citation(s) → Pages`中填写。

如可视化界面被本机安全策略阻止，仍可使用原有的`安装全部中文学术格式.cmd`或`INSTALL-ALL.cmd`。

## 包内文件

- `Styles`：18套可安装的EndNote ENS脚注样式；
- `打开中文学术格式工具箱.cmd`：可视化工具箱入口；
- `StyleToolbox.ps1`：Windows原生图形界面程序；
- `格式选择中心.html`：按学科、机构和规则族检索样式并查看示例；
- `格式库测试矩阵.xlsx`：108项Word/WPS回归测试记录表；
- `64条标准测试文献.ris`：可直接导入EndNote的覆盖测试集；
- `统一多语种文献类型.xml`：中文、英文、日文资料的统一字段类型表；
- `style-manifest.json`：样式来源、状态、文件校验值和规则族清单；
- `THIRD_PARTY_NOTICES.md`：第三方来源及许可说明。

## 当前状态

- 《中国社会科学（2026）》：已完成EndNote X9＋WPS基础实测。
- 其余17套：结构通过自动校验，规则依据相应CSL样例映射，属于预览版，必须在文档副本中试用。
- 所有样式均关闭脚注文献汇总到正文/文末参考文献表的选项。
- 脚注序号由Word/WPS控制，ENS不控制编号外观。

## 重要边界

样式只能排列EndNote记录中已经存在的字段，不能凭空补出缺失的译者、出版社、学校、访问日期或卷期信息。英文、日文资料要稳定实现多语种格式，仍需使用包内统一参考类型表并按说明整理记录。
